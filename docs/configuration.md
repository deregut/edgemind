# 設定說明

除了 [`.env.example`](../.env.example) 中的資料庫、物件儲存與兩把金鑰之外，EdgeMind 的所有設定都在網頁介面完成，並存在資料庫中（API Key、密鑰、MCP 憑證以 `ENCRYPTION_KEY` 做 AES-256-GCM 加密）。本文依介面位置逐一說明。

設定頁分頁：**供應商 ｜ Agent 與權限 ｜ 知識庫 ｜ Skills ｜ MCP ｜ 記憶 ｜ 密鑰 ｜ 儲存空間 ｜ 帳號安全 ｜ 外觀**；另外側邊欄有 **排程** 與 **用量** 兩個獨立頁面，專案頁也有專案層級的設定。

設定的優先順序（下層覆蓋上層）：**全域設定 → 專案設定 → 單一對話設定**。

---

## 1. 供應商

**設定 → 供應商**，依類型分為 LLM、搜尋、Embedding、Rerank、圖片五類。每個供應商都有：

| 欄位 | 說明 |
|---|---|
| 名稱 | 顯示用 |
| 類型／種類 | 決定使用哪種 API 格式 |
| Base URL | 預設會自動帶入；自架或代理服務改成自己的網址 |
| API Key | 加密存放，儲存後只顯示遮罩預覽；編輯時留空代表沿用原值 |
| 啟用 | 停用後不會被使用，但設定保留 |
| 優先順序 | 數字越小越優先；搜尋與圖片供應商依此順序選用與備援 |
| 額外設定 | 依種類而定（見下） |

每個供應商都可以 **測試連線**；LLM、部分 Embedding 與圖片供應商可以 **抓取模型清單**。

### 1.1 LLM：三種協定

EdgeMind 自己實作三種 LLM 協定，所有廠商都對應到其中一種。新增時可以選預設範本，只是幫你帶入名稱與網址：

| 範本 | 協定 | 預設 Base URL |
|---|---|---|
| OpenAI | OpenAI 相容 | `https://api.openai.com/v1` |
| Anthropic | Anthropic Messages | `https://api.anthropic.com` |
| Google Gemini | Gemini generateContent | `https://generativelanguage.googleapis.com` |
| OpenRouter | OpenAI 相容 | `https://openrouter.ai/api/v1` |
| DeepSeek | OpenAI 相容 | `https://api.deepseek.com/v1` |
| Groq | OpenAI 相容 | `https://api.groq.com/openai/v1` |
| Mistral | OpenAI 相容 | `https://api.mistral.ai/v1` |
| xAI | OpenAI 相容 | `https://api.x.ai/v1` |
| Ollama（公開端點） | OpenAI 相容 | 你的公開網址 + `/v1`（API Key 選填） |
| OpenAI 相容（自訂） | OpenAI 相容 | 任何相容端點（vLLM、LM Studio、LiteLLM…，須可從網路連線） |

**OpenAI 相容**的額外設定：

| 鍵 | 說明 |
|---|---|
| `api` | `chat`（預設，Chat Completions）或 `responses`（OpenAI Responses API；推理模型的推理內容可跨回合保留） |
| `extraHeaders` | 額外 HTTP 標頭，每行一個 `Name: value` 或一個 JSON 物件（例如 OpenRouter 的 `HTTP-Referer`） |
| `streamUsage` | 是否送出 `stream_options.include_usage`（預設 `true`）；不支援的相容端點請設 `false` |
| `replayReasoning` | 把 `reasoning_content` 回傳給模型（DeepSeek 思考模式＋工具呼叫時需要；預設 `false`） |

**Anthropic Messages** 與 **Gemini** 可設定 `extraHeaders`。Anthropic 的思考區塊（含簽章與 redacted_thinking）、Gemini 的 thoughtSignature 都會在工具呼叫往返時正確保留。

**模型清單**：供應商 ⋯ 選單 → **模型清單**，從 API 抓到的清單勾選要使用的模型，或手動輸入模型 ID。每個模型可標記能力：

- **視覺**：可以接收圖片（未勾選時圖片不會送出，改成一行文字提示）
- **工具**：可以呼叫工具（未勾選時不提供工具，過去的工具呼叫會轉成文字）
- **推理**：推理模型；聊天頁會顯示推理強度選擇器，並顯示思考過程

抓取清單時若供應商提供上下文長度，會一併保存，用於對話壓縮的判斷。

**模型價格**：在 **Agent 與權限 → 模型價格** 設定（見第 2 節），沒有價格的模型不計入花費。

### 1.2 搜尋（`web_search`）

| 種類 | 需要 | 備註 |
|---|---|---|
| Tavily | API Key | `https://api.tavily.com` |
| Serper | API Key | Google 搜尋結果 |
| SearXNG（自架） | Base URL；API Key 選填（以 Bearer 送出） | 必須在 SearXNG 的 `settings.yml` 的 `search.formats` 啟用 `json`；伺服器須能從公開網路連線 |
| Jina Search | API Key | `https://s.jina.ai`；設定後 `web_fetch` 的 Jina Reader 備援也會使用這把 Key |
| Google Programmable Search | API Key + 搜尋引擎 ID（`cx`） | 每次最多 10 筆 |

- 可設定多個，依 **優先順序** 使用；某個供應商失敗或 **0 筆結果** 時自動改用下一個。
- 結果一律限長：標題 ≤ 200 字、摘要 ≤ 300 字、總量 ≤ 4,000 字；需要全文時模型會再呼叫 `web_fetch`。
- 沒有任何啟用的搜尋供應商時，`web_search` 會回報錯誤，`web_fetch` 仍可使用。

### 1.3 Embedding

用於知識庫與記憶的向量化。測試連線會回報向量維度。

| 種類 | 預設 Base URL | 建議模型 |
|---|---|---|
| OpenAI | `https://api.openai.com/v1` | `text-embedding-3-small`、`text-embedding-3-large` |
| Gemini | `https://generativelanguage.googleapis.com` | `gemini-embedding-001` |
| Jina | `https://api.jina.ai/v1` | `jina-embeddings-v3` |
| Voyage | `https://api.voyageai.com/v1` | `voyage-3.5`、`voyage-3.5-lite`、`voyage-code-3` |
| Cohere | `https://api.cohere.com` | `embed-v4.0`、`embed-multilingual-v3.0` |
| Mistral | `https://api.mistral.ai/v1` | `mistral-embed` |
| OpenAI 相容 | 自訂 | 任何相容端點 |
| Cloudflare Workers AI | `https://api.cloudflare.com/client/v4` | 例如 `@cf/baai/bge-m3`；REST 需 Account ID + Token，部署在 Cloudflare 且啟用 AI 綁定時可不填 Token（`useBinding=true` 可強制走綁定） |

- 支援指定維度的模型（OpenAI v3、Jina v3/v4、Voyage、Cohere embed-v4、Mistral、Gemini）可以在建立知識庫時指定較小的維度以節省空間。
- 2,000 維以內使用 `vector` 索引，2,001–4,000 維自動改用 `halfvec` 索引。

### 1.4 Rerank（重排序）

Jina Reranker、Cohere Rerank、Voyage Rerank。Rerank 不是全域開關，而是在**建立或編輯知識庫時**為該知識庫選擇；檢索時取前 3×K（最多 50）筆候選再重排。

### 1.5 圖片（`image_generate`）

| 種類 | 說明 |
|---|---|
| OpenAI 相容 Images | `/images/generations`，例如 `gpt-image-1` |
| Gemini（圖片模型） | 例如 `gemini-2.5-flash-image` |
| Cloudflare Workers AI | 例如 `@cf/black-forest-labs/flux-1-schnell`，需 Account ID |

`image_generate` 使用優先順序最高的啟用中圖片供應商與其第一個啟用的模型；只能在專案中使用，產生的圖片存成專案檔。

## 2. Agent 與權限

**設定 → Agent 與權限**

### 預設值

| 設定 | 說明 |
|---|---|
| 預設模型 | 新對話預設使用的模型；專案可以覆蓋 |
| 自動命名使用的模型 | 第一次回覆後自動產生對話標題；留空時使用該對話的模型 |
| 全域權限模式 | 見下方權限模式；專案與對話可以覆蓋 |
| 每次執行的步數上限 | 1–200，預設 25；一個「步」是一次模型呼叫 |

### 權限模式

每個工具都有風險等級：**讀取**、**寫入**、**危險**、**外部副作用**（MCP 工具依其標註判斷，可手動調整）。

| 模式 | 讀取 | 寫入 | 危險／外部副作用 |
|---|---|---|---|
| 唯讀（Plan） | 自動 | 禁止（不提供給模型） | 禁止（不提供給模型） |
| 一般（預設） | 自動 | 詢問 | 詢問 |
| 自動編輯 | 自動 | 自動 | 詢問 |
| 全部權限 | 自動 | 自動 | 自動（顯示醒目警告，受下方上限限制） |
| 自訂 | 依工具規則 | 依工具規則 | 依工具規則 |

- 模式可以在**全域**（此頁）、**專案**（專案設定）、**單一對話**（聊天頁上方的權限選擇器）設定，下層覆蓋上層；未設定時繼承上層。
- 每次詢問時可選：**本次允許**、**本對話一直允許**（只把該工具在這個對話中的「詢問」變成「允許」，不會覆蓋「禁止」）、**拒絕**（模型會收到被拒絕的結果並繼續）。
- `ask_user`（向你提問）在唯讀模式也能使用。
- 所有工具呼叫與權限決定都寫入稽核紀錄。
- **排程任務**以任務設定的權限模式執行；需要批准的工具會讓任務停在「等待批准」，直到你在對話中批准。無人值守的任務請使用「全部權限」並設好上限。

**自訂模式的工具規則**：每條規則是「工具名稱（可用 `*` 萬用字元，例如 `mcp__github__*`）＋ 允許／詢問／禁止」，範圍可以是全域、專案或單一對話，並可加條件：

- `pathGlob`：檔案工具只在路徑符合時套用，例如 `docs/**`
- `domains`：`http_request`／`web_fetch` 只在網域符合時套用，例如 `api.example.com`、`*.github.com`

比對順序：對話 > 專案 > 全域；完全相同的工具名稱 > 萬用字元 > `*`；有條件的規則優先。在非自訂模式下，規則只能讓權限**更嚴格**。

> 目前介面還沒有規則編輯器，自訂規則透過 API 設定。登入後在瀏覽器開發者工具的 Console 執行，例如「`file_write` 只允許 `docs/**`」：
>
> ```js
> const csrf = document.cookie.match(/em_csrf=([^;]+)/)[1];
> await fetch("/api/permissions/policies", {
>   method: "POST",
>   headers: { "content-type": "application/json", "x-csrf-token": csrf },
>   body: JSON.stringify({ scope: "global", toolName: "file_write", action: "allow", rule: { pathGlob: "docs/**" } }),
> }).then((r) => r.json());
> ```
>
> `GET /api/permissions` 列出目前的規則與工具清單，`DELETE /api/permissions/policies/<id>` 刪除規則。專案或對話範圍請加 `scopeId`（專案或對話的 ID）。

### 「全部權限」模式上限

| 設定 | 預設 |
|---|---|
| 步數上限 | 50 |
| Token 上限（輸入＋輸出） | 2,000,000 |
| 花費上限（USD） | 不限（需要先設定模型價格） |

任一上限達到時，執行會停止並說明原因。

### 模型價格

每百萬 tokens 的美元價格：**輸入**、**快取輸入**（留空時以輸入價格計算）、**輸出**（含推理 tokens）。用於「用量」頁的花費統計、花費上限與「全部權限」的花費上限。沒有價格的模型不計費，「用量」頁會顯示未計價的呼叫次數。

## 3. 知識庫

**設定 → 知識庫**（全域）與 **專案 → 知識庫**（專案專屬）。

建立知識庫時設定：

| 欄位 | 說明 |
|---|---|
| 名稱、說明 | 模型會看到名稱與說明，用來判斷要搜尋哪個知識庫 |
| Embedding 供應商／模型／維度 | 建立時會實際呼叫一次確認維度；不選則為純全文檢索的知識庫 |
| Rerank 供應商／模型 | 選填 |
| 切塊大小／重疊 | 預設 1,000／150 字元；只影響之後上傳的文件 |

- 上傳：拖曳檔案即可，瀏覽器會解析（txt、md、程式碼、csv、json、html、PDF、DOCX）並切塊後上傳；掃描型 PDF（沒有文字層）會被拒絕。
- 進度條顯示索引狀態；出錯時按 **繼續索引** 從中斷處接續。頁面開著時會自動驅動索引。
- **更換 Embedding 模型或維度**會重建整個知識庫的索引（背景分批進行），期間仍可使用全文檢索。
- **測試搜尋**框可以直接試查詢結果與分數；也可以檢視每份文件的切塊。
- 對話會自動附加：全域知識庫 ＋ 所在專案的知識庫，模型透過 `kb_search` 檢索並以 `[n]` 標註引用。

## 4. Skills

**設定 → Skills**；**專案 → Skills** 可以限定專案可用的 Skills（不設定時全部可用）。

- 格式：一個資料夾，含 `SKILL.md`（YAML 前置資料必須有 `name` 與 `description`）以及任意參考檔與腳本。`name` 只能用小寫英文、數字與單一連字號（≤ 64 字元），`description` ≤ 1,024 字元。
- 系統提示只放已啟用 Skills 的名稱與描述；模型需要時以 `skill_load` 讀取全文與附檔。
- 操作：
  - **新增 Skill**：線上編輯器（檔案樹，可新增／刪除檔案）
  - **上傳 zip**：可一次包含多個 Skill（每個含 `SKILL.md` 的最外層資料夾視為一個），可選擇覆蓋同名 Skill；格式不完全正確時會自動修正並回報
  - **從 GitHub 匯入**：貼上 repo、tree、blob 或 raw 網址；私有 repo 或避免 API 限流可設定 **GitHub Token**（加密存放）
  - **匯出 zip**、啟用／停用、刪除
- 限制：每個 Skill 最多 200 個檔案、單檔 5 MB、合計 20 MB。
- 模型可以用 `skill_write` 建立或修改 Skill（屬於「寫入」風險，依權限模式詢問）。
- 內建 Skills：`e2b-sandbox`、`self-hosted-runner`（見第 7 節）；可以停用、編輯或刪除，刪除後不會自動重新安裝。

## 5. MCP

**設定 → MCP**；**專案 → MCP** 可以限定專案可用的伺服器。

新增伺服器：

| 欄位 | 說明 |
|---|---|
| 名稱 | 也用來產生工具前綴，模型看到的工具名稱為 `mcp__{前綴}__{工具}` |
| 網址 | 遠端 MCP 端點（不支援 stdio 本地伺服器） |
| 傳輸方式 | **Streamable HTTP**（新版，建議）或 **SSE（舊版）** |
| 授權方式 | **無**、**Bearer Token**、**自訂 Header**、**OAuth 2.1** |

OAuth 2.1：

- 支援自動探索（Protected Resource Metadata、Authorization Server Metadata）、動態用戶端註冊、PKCE。
- 伺服器不支援動態註冊時，填入 **Client ID**（以及必要時的 **Client Secret**、**Scope**）。對話框中顯示的回呼網址（`https://你的網域/api/mcp/oauth/callback`）需要登記到該服務。
- 按 **授權** 會轉到服務商頁面登入，完成後回到設定頁；權杖到期前自動更新。

工具管理：

- **同步** 重新抓取工具清單（保留你對個別工具的啟用狀態與風險設定）。
- 每個工具可以個別啟用／停用、調整風險等級（讀取／寫入／危險／外部副作用），也可以檢視參數結構。
- 預設風險：標註 `readOnlyHint` → 讀取；標註非破壞性且不對外 → 寫入；其餘 → 外部副作用。
- MCP 網址由你設定，因此不經過 SSRF 過濾（可以連到私有網路中的伺服器，前提是部署平台能連到）。

## 6. 記憶

**設定 → 記憶**；**專案 → 記憶** 顯示專案記憶。

| 設定 | 預設 | 說明 |
|---|---|---|
| 自動召回 | 開 | 每回合依使用者訊息語意搜尋相關記憶放入上下文 |
| 每回合召回筆數 | 5 | 1–20 |
| 相似度門檻 | 0.35 | 0–1，向量模式下低於門檻的不放入 |
| 自動萃取 | 開 | 對話完成後由輔助模型整理出值得長期記住的事（新增或更新），會略過明顯的密鑰與過短的訊息 |
| 輔助模型 | 對話所用的模型 | 用於萃取記憶與壓縮摘要；建議選便宜快速的模型 |
| 記憶用的 Embedding 模型 | 第一個啟用的 Embedding 供應商 | 更換後按旁邊的重新向量化按鈕更新既有記憶 |
| 對話壓縮 | 開 | 上下文用量達到 **觸發門檻**（預設 70%）時，把較早的內容壓縮成摘要 |
| 保留最近（比例） | 25% | 壓縮時保留最近這個比例的原文 |
| 預設上下文長度 | 128,000 tokens | 模型沒有上下文長度資訊時使用 |

- 記憶清單可以搜尋、依範圍（全域／專案／對話）與來源（手動新增／自動萃取／模型儲存）篩選、直接編輯、刪除，或全部刪除。
- 聊天頁 ⋯ 選單的 **壓縮較早的對話** 可以手動壓縮。
- 沒有 Embedding 供應商時，記憶以關鍵字比對運作。

## 7. 密鑰

**設定 → 密鑰**：給 `http_request` 使用的機密值（API Key、權杖、甚至整個私有服務網址）。

| 欄位 | 說明 |
|---|---|
| 名稱 | 英文字母、數字、底線，不可以數字開頭，≤ 64 字元，例如 `E2B_API_KEY`；區分大小寫，必須和 `{{secret:名稱}}` 完全相同。前後空白、全形字元（`ＥＲＲ＿ＫＥＹ`）與看不見的字元（零寬空白等）會自動整理，對話框會顯示「將儲存為：…」；其他字元（例如 `-`、中間的空白）會被拒絕並說明原因 |
| 值 | 只能寫入，之後只顯示遮罩預覽 |
| 允許網域 | 每行一個；`api.example.com` 或 `*.example.com`（只含子網域）；**空白代表任何網域都不允許** |
| 說明 | 選填，模型看得到 |

- 模型在 `http_request` 中寫 `{{secret:名稱}}`，伺服器送出前才解密代入；模型、執行紀錄、稽核紀錄都看不到真值。
- 回應、錯誤訊息與存檔中出現的密鑰值（含 URL 編碼、JSON 跳脫、Base64 形式）都會被遮蔽。
- 重新導向到不在允許清單的網域時不會跟隨。
- 儲存失敗時，對話框會保持開啟並顯示伺服器的錯誤訊息（輸入內容不會因為點到外面而消失）；清單載入失敗時會在此頁顯示原因與「重試」，不會一直轉圈。儲存成功後會重新載入清單並確認新密鑰確實在清單中。
- 對話中找不到密鑰時，`http_request` 的錯誤會說明是「這個部署的資料庫裡沒有任何密鑰」，還是名稱不符（並列出現有名稱與大小寫相近的名稱）。密鑰存在 `DATABASE_URL` 指向的資料庫中：在 Deploy Preview 或分支部署（可能使用不同的資料庫）存的密鑰，正式網址看不到。
- 內建 Skills 需要的密鑰：
  - `e2b-sandbox`：`E2B_API_KEY`，允許網域 `api.e2b.app`（只有建立／刪除沙盒會用到；之後的執行改用沙盒回傳的存取權杖）
  - `self-hosted-runner`：`PISTON_URL`／`PISTON_KEY` 或 `JUDGE0_URL`／`JUDGE0_KEY`，允許網域為你的伺服器網域（伺服器必須可從公開網路連線，內網位址會被 SSRF 防護擋下）

## 8. 儲存空間

**設定 → 儲存空間** 顯示物件儲存的連線狀態（來自環境變數）、bucket 名稱，以及目前已設定 CORS 的網站來源。

- 目前網址尚未加入 CORS 時，可以按鈕立即套用；服務商不允許以 API 設定時，請依畫面說明到服務商後台設定（允許 `GET`／`PUT`／`HEAD`、所有標頭、公開 `ETag`）。
- 專案檔案上傳：單檔 32 MB 以下一次上傳，以上自動分段（每段 ≥ 8 MB），單檔最大 5 GB。

## 9. 帳號安全與外觀

- **帳號安全**：變更密碼（至少 10 個字元）。變更後除了目前的瀏覽器，其他登入的裝置都會被登出。忘記密碼的處理方式見 [deploy-netlify.md 第 5 節](deploy-netlify.md#5-立即設定登入密碼重要)。
- **外觀**：淺色、深色或跟隨系統。

## 10. 專案

**專案的對話**：

- 在專案中開始的對話（專案頁或側邊欄的「在專案中新對話」）會存成該專案的對話，之後的每一輪都留在同一個對話裡。
- 側邊欄點專案名稱會**接續該專案最近的對話**（顯示完整歷史）；專案還沒有對話時開啟專案頁。左邊的箭頭展開／收合專案底下的對話（最新的在上），滑鼠移到專案上會出現專案首頁的連結。
- 側邊欄的「已釘選」與「最近對話」只列**不屬於任何專案**的對話。
- **專案頁 → 對話**：最新的在上，「繼續最近的對話」、「在專案中新對話」、「加入現有對話」（勾選專案以外的對話一次移入），每列右側可「移出專案」。
- 任何對話的「⋯」選單：「移到專案…」／「移到其他專案…」與「移出專案」。移入後，之後的回覆會使用該專案的指示、檔案、知識庫與工具設定。
- API：`GET /api/conversations?projectId=<專案 ID>` 只列該專案的對話，`projectId=none` 只列不屬於任何專案的對話（其他值回 400）；`PATCH /api/conversations/<id>` 的 `{ "projectId": "<專案 ID>" | null }` 移入／移出。

**專案頁 → 設定**：

| 設定 | 說明 |
|---|---|
| 名稱、指示 | 指示會加入這個專案中所有對話的系統提示 |
| 預設模型 | 覆蓋全域預設模型 |
| 權限模式 | 覆蓋全域權限模式 |
| 啟用的工具 | 不設定時全部可用；勾選後只提供勾選的工具（含 MCP 工具） |

另外有 **檔案**（專案檔案空間，版本與還原）、**知識庫**、**Skills**、**MCP**、**記憶** 分頁。`file_*`、`image_generate`、`code_run` 寫回檔案等功能只在專案中的對話可用。

## 11. 程式執行（`code_run`）

沒有獨立的設定頁，行為如下：

- **JavaScript**：伺服器端 QuickJS，記憶體 64 MB、預設逾時 10 秒（最長 30 秒），沒有網路、計時器與 Node API。可掛載專案檔（合計 ≤ 10 MB、≤ 200 個檔案），寫入的檔案存回專案並保留舊版本。Cloudflare 免費方案的 10 ms CPU 限制下幾乎無法使用。
- **Python**：在瀏覽器以 Pyodide 執行（第一次從 jsDelivr 下載約數十 MB，之後快取），常用套件依 `import` 自動安裝，matplotlib 圖表自動存成 PNG。需要開著聊天分頁；背景模式與排程任務中不可用。
- 輸出各最多 20,000 字元，過長時完整內容存成專案檔 `code_run_outputs/…`。
- 需要完整 Linux 環境或其他語言時，使用內建 Skills `e2b-sandbox`（E2B 雲端沙盒）或 `self-hosted-runner`（自架 Piston／Judge0），搭配「密鑰」與 `http_request`。
- E2B 預設映像的 Node 較舊：`e2b-sandbox` 會在需要時把新版 Node（預設 LTS 26）裝到沙盒家目錄；常用的話可照 Skill 內 `references/node-template.md` 建一個預裝新版 Node 的自訂模板，並在專案指示寫明模板名稱。

## 12. 排程

側邊欄 **排程**。

| 欄位 | 說明 |
|---|---|
| 名稱、提示詞 | 每次執行會建立新對話「[排程] 名稱」並送出提示詞 |
| 專案 | 選填；在專案中執行（可使用專案檔與知識庫） |
| 模型 | 留空使用預設模型；指定的模型被刪除時改用預設模型 |
| 權限模式 | 需要批准的工具會讓執行停在「等待批准」；無人值守請用「全部權限」 |
| 頻率 | **一次**（指定日期時間）、**間隔**（每 N 分鐘，至少 5）、**每日**、**每週**、**cron**（5 欄位：分 時 日 月 星期） |
| 時區 | IANA 時區，例如 `Asia/Taipei`；日光節約時間自動處理 |

- 編輯時即時預覽接下來 5 次執行時間；**立即執行** 可以馬上跑一次；**紀錄** 顯示每次執行的狀態與對話連結。
- **觸發器** 卡片：Netlify 部署內建每 15 分鐘觸發，不需設定；Cloudflare 部署需要產生 token 並設定外部觸發（見 [deploy-cloudflare.md 第 7 節](deploy-cloudflare.md#7-排程任務的觸發)）。卡片顯示最近一次觸發的時間與來源。
- 實際執行時間取決於觸發頻率，最多晚一個週期；停擺期間錯過的時段不補跑。

## 13. 用量與花費上限

側邊欄 **用量**。

- 依日期範圍顯示 tokens（含快取輸入與推理 tokens）與花費，並依模型、類型（聊天、命名、記憶萃取、子代理…）、對話、專案分類。
- **花費上限**：

  | 設定 | 預設 | 說明 |
  |---|---|---|
  | 每日上限（USD） | 不限 | |
  | 每月上限（USD） | 不限 | |
  | 警告比例 | 80% | 達到時在執行中記錄一次警告，側邊欄也會提示 |
  | 時區 | UTC | 用來計算「今天」與「本月」 |

  每次呼叫模型前都會檢查；超過上限時執行會停止並說明原因，自動命名與記憶萃取也會暫停，直到下一個計算週期或你調高上限。
- 只有設定了價格的模型會計入花費（見第 2 節「模型價格」）。目前 Embedding、Rerank、搜尋、圖片與對話壓縮摘要不計入花費。
